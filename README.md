# TANK CAT: Operation Fish

Пиксельные «танчики» с рикошетом для геймджема FunFlow. Кот в танке едет через арены к рыбе, по пути давит жуков и членистоногих, а снаряды отскакивают от стен.

Референсы: Battle City, Wii Tanks.

## Как играть

| Клавиша | Действие |
|---|---|
| **W / S** | вперёд / назад |
| **A / D** | поворот корпуса |
| **Мышь** | башня следит за курсором |
| **ЛКМ** | основной выстрел с рикошетом |
| **ПКМ (зажать)** | пулемёт: магазин на 4 патрона, потом перезарядка |
| **Q (зажать и отпустить)** | ульта «Орех»: время замедляется, отпусти — орех падает в точку прицела |
| **Esc / P** | пауза |

**Цель уровня** — доехать до рыбы, к ней ведёт стрелка у края экрана.

**Звёзды за уровень:**
- ★ доехать до рыбы;
- ★ раздавить всех жуков;
- ★ пройти без попаданий.

**Game Over** — когда у кота кончились HP. Рекорд (уровень и звёзды) сохраняется.

## Механика

- **Рикошет.** Снаряд отскакивает от стен. Линия прицела показывает траекторию с отскоком, и её считает тот же код, что и полёт снаряда, поэтому она не врёт.
- **Свой снаряд опасен.** После рикошета он ранит и кота.
- **Снаряды сбивают друг друга:** свою пулю можно подставить под вражескую.
- **Лимит:** не больше 5 снарядов в полёте, как в Wii Tanks. Боезапас виден в HUD, а прицел показывает, готов ли выстрел.
- **Враги** честно предупреждают об атаке:

| Враг | Поведение | HP |
|---|---|---|
| **Клещ** | бежит к коту, замирает и мигает (замах), затем делает рывок | 2 |
| **Жук** | стоит у укрытия, стреляет с рикошетом; перед выстрелом мигает и показывает пунктир траектории | 4 |
| **Краб** (босс) | сторожит выход, ходит и стреляет; полоска HP внизу экрана | 10 |

- **Урон:** основное орудие — 2, пулемёт — 1, по коту любой снаряд — 1.
- **Сложность растёт:** с каждым уровнем больше врагов, пули быстрее, предупреждения короче.
- **Уровни** генерируются: комнаты, коридоры и укрытия разные каждый раз.

## Запуск

1. Unity **6000.6.5f1** (URP 2D).
2. Открыть сцену `Assets/Scenes/SampleScene`.
3. ▶ Play.

### Как устроено

- **`GameFlow`** ведёт игру: меню → уровень → победа/смерть → следующий уровень / Game Over. Всё остальное подписывается на его события.
- **`LevelContext`** — всё про текущий уровень. Объекты на уровне получают его через `ILevelActor.Init`, синглтонов нет.
- **Звук, эффекты и «ощущение удара»** (`SfxPlayer`, `FxPlayer`, `HitFeel`) слушают события. Геймплей про них не знает.
- **`GameTime`** — единственное место, которое меняет `Time.timeScale` (пауза, замедление ульты, стоп-кадры).
- **`GameSettings`** — сохранения игрока: звук, туториал, рекорд.

## Как сделать типичные вещи

**Нового врага — без кода.**
1. `Create → CatTanks → Enemy Definition` в `Assets/Data/Enemies`.
2. Задать спрайт, HP, ходит ли и стреляет ли он, где и как часто появляется.
3. Добавить ассет в список **Enemies** компонента EntitySpawner.

**Босса.** В ассете врага включить **Boss** и задать **Boss Nameplate** (табличку с именем). Вместо полоски над головой у него появится большая полоска HP внизу экрана.

**Баланс:**

| Что | Где |
|---|---|
| Генерация, звёзды, рост сложности | `Assets/Data/LevelConfig_Default` |
| HP кота | префаб `PlayerTank` → **Health → Max Hp** |
| Оружие (урон, магазин, размер пуль) | префаб `PlayerTank` → **PlayerTank** |
| Попытки на забег | в сцене **GameFlow → Start Lives** |
| Стоп-кадры и тряска | **HitFeel** |
| Полоски HP над врагами | `FxLibrary` |

**UI.**
1. Картинки положить в `Assets/Art/UI` с ожидаемым именем (`button_start`, `pause_restart`, `hp_frame`, `star_active`…). Сборка подставит их сама.
2. Выполнить **CatTanks → UI → Собрать префабы UI**.
3. Ручные правки префабов в `Assets/Prefabs/UI` не теряются: сборщик заметит изменённые экраны и спросит, перезаписать их или оставить. Отпечатки хранятся в `Assets/Prefabs/UI/.ui-bake.json`, коммитьте его.
4. **CatTanks → UI → Пересобрать один экран** пересобирает только выбранный экран.

**Свои звуки и музыка.** Положить файлы в `Assets/Resources/Sfx/` (имя как у `SfxId`, например `Shot.wav`) или в `Assets/Resources/Music/` (`Menu.ogg`, `Battle.ogg`). Они заменят синтез автоматически.

## Команды редактора

| Меню | Что делает |
|---|---|
| CatTanks → UI → Собрать префабы UI | собрать UI-префабы по теме (с сохранением ручных правок) |
| CatTanks → UI → Пересобрать один экран | пересобрать только один экран |
| CatTanks → Сохранения → Показать обучение снова | следующий START снова покажет туториал |
| CatTanks → Сохранения → Сбросить рекорд | стереть лучший результат |
| CatTanks → Export SFX to WAV | выгрузить синтезированные звуки в файлы |

**Отладка в игре** (если в GameFlow включено **Debug Keys**): **R** — новый уровень, **N** — пропустить уровень, **U** — заряд ульты. Перед сдачей отключить.

**Тесты:** Window → General → Test Runner → EditMode → Run All.
